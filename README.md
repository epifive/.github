# epifive/.github

Organisation profile for [github.com/epifive](https://github.com/epifive). `profile/README.md` is
shown on the organisation page; the banner, project cards and stats in `profile/assets/` are
generated by [`scripts/build.mjs`](scripts/build.mjs) (Node, no dependencies) and refreshed daily
by a GitHub Action.

```bash
GITHUB_TOKEN=... node scripts/build.mjs
```
